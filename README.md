# David Kim Portfolio

Static GitHub Pages portfolio for David Kim, focused on experience, applied data projects, and education.

## Site Contents

- Experience at Cargill Limited
- Project cards for CrisisPulse and BidReader
- Education at Georgia Institute of Technology and University of Waterloo
- Linked CrisisPulse paper in `assets/crisispulse-paper.pdf`
- Profile photo and organization logos in `assets/`

## Development

The site is plain HTML, CSS, and JavaScript. To preview locally:

```powershell
python -m http.server 8000
```

GitHub Pages serves the site from the repository root on the `master` branch.
